## 📝 Descrição

Este projeto tem como objetivo o desenvolvimento de um **Sistema de Caixa Ponto de Venda (PDV)** com Interface Gráfica, utilizando **Python**, **Flask**, **SQLAlchemy** e banco de dados **PostgreSQL**. O sistema visa atender pequenos empreendedores, oferecendo funcionalidades como:

- Cadastro de produtos
- Gestão de estoque
- Controle de vendas
- Emissão de relatórios
- Integração com gateways de pagamento

## 🎯 Objetivo

Desenvolver um **sistema de PDV intuitivo e eficiente**, que permita aos empreendedores gerenciar suas vendas, produtos, clientes e estoque de forma simples e prática.

---

## ⚙️ Funcionalidades

- **Cadastro de Produtos**: Permite adicionar, editar e excluir produtos.
- **Gestão de Estoque**: Controle de quantidade de produtos com alertas para estoque baixo.
- **Vendas**: Realização de vendas com opções de pagamento (dinheiro, cartão e Pix).
- **Relatórios**: Geração de relatórios de vendas e produtos.
- **Segurança**: Sistema de autenticação com hash de senhas.
